## Шашки (Упрощенная Версия)

Данный код реализует игру в упрощенные шашки для двух игроков. Основные особенности:

1.  **Упрощенные правила:** За один ход можно съесть не более одной шашки. Дамки и другие сложные правила не реализованы.
2.  **Шахматная нотация:** Ходы вводятся в шахматной нотации, например, `a2 b3`.

### Архитектура кода

#### 1. Библиотеки и макросы

В начале кода подключаются необходимые библиотеки:

*   `<iostream>`: Для ввода и вывода данных.
*   `<vector>`: Для работы с динамическими массивами.
*   `<string>`: Для работы со строками.
*   `<algorithm>`: Для использования алгоритмов, таких как преобразование регистра.
*   `<windows.h>` (условно): Чтобы обеспечить корректное отображение символов Unicode в консоли Windows.

Определены макросы для представления фигур на доске:

*   `WHITE_CHECKER`: Символ для белой шашки.
*   `BLACK_CHECKER`: Символ для черной шашки.

#### 2. "Скелет" программы

Объявляются forward declarations классов `Board`. Это необходимо для того, чтобы класс `Piece` мог ссылаться на класс `Board`, и наоборот, без необходимости менять порядок объявления классов.

Сначала видим структуру кода. Уже позже реализованы сами классы, их методы и использованные функции.

Запуск программы производится в самом конце -- в функции `main()`. После этого ввод и вывод данных производится в терминале. Вывод работает корректно в `Linux`, в `Windows 10` требуется дополнительно работать в `gdb`.

##### Как работает программа:

1. Открыть терминал/PowerShell.
2. Командой `cd path`, где `path` - путь до директории с местонахождением файла `main_checkers4.cpp`, открыть указанную директорию.
3. Командой `g++ main_checkers4.cpp -g` создать файл для выполнения.
4. Командой `.\a.exe` запустить файл для выполнения. На экран выведется начальное состояние доски. Первый ход у белых фигур.
4. Последующими командами вида `[начальная клетка перемещаемой фигуры] [конечная клека перемещаемой фигуры]` воспроизводятся коды.
5. При необходимости партию можно закончить введя `exit` или прервав работу кода внутренними командами терминала.

#### 3. Классы

В коде реализованы следующие классы:

*   **`Piece` (Фигура):**
    *   Базовый класс для представления шашки.
    *   Содержит информацию о цвете шашки (`WHITE` или `BLACK`).
    *   Метод `isValidMove()` определяет, является ли ход допустимым для данной шашки, учитывая текущее состояние доски.
    *   Метод `getSymbol()` возвращает символ, которым отображается шашка на доске.

*   **`Board` (Доска):**
    *   Представляет игровое поле.
    *   Хранит указатели на объекты `Piece` в двумерном массиве `board[8][8]`.
    *   Методы:
        *   `setupBoard()`: Устанавливает начальное положение шашек на доске.
        *   `printBoard()`: Выводит текущее состояние доски в консоль.
        *   `getPiece(row, col)`: Возвращает указатель на фигуру, находящуюся в указанной клетке.
        *   `setPiece(row, col, piece)`: Устанавливает фигуру в указанную клетку.
        *   `isLegalMove(startRow, startCol, endRow, endCol, currentPlayer)`: Проверяет, является ли ход допустимым для текущего игрока.
        *   `makeMove(startRow, startCol, endRow, endCol)`: Выполняет ход, перемещая шашку.
        *   `undoMove(startRow, startCol, endRow, endCol, capturedPiece)`: Отменяет ход (не реализовано в текущей версии).

*   **`Game` (Игра):**
    *   Управляет игровым процессом.
    *   Содержит объект `Board`.
    *   Отслеживает текущего игрока (`currentPlayer`).
    *   Методы:
        *   `startNewGame()`: Начинает новую игру.
        *   `playGame()`: Запускает игровой цикл.
        *   `getUserInput()`: Получает ввод от пользователя (шахматная нотация хода).
        *   `processMove(move)`: Обрабатывает ход, введенный пользователем.
        *   `switchPlayer()`: Переключает текущего игрока.
        *   `algebraicToCoord(square)`: Преобразует шахматную нотацию (например, "a2") в координаты (row, col) на доске.
        *   `coordToAlgebraic(row, col)`: Преобразует координаты (row, col) в шахматную нотацию.

#### 4. Реализация методов классов

После объявления классов следует реализация методов, определенных внутри каждого класса. Это включает в себя логику инициализации доски, проверки допустимости ходов, выполнения ходов и т.д.

#### 5. Функции (не члены классов)

В данном коде присутствуют только функции, являющиеся методами соответствующих классов.

#### 6. `main()`

Функция `main()` является точкой входа в программу.  Она создает экземпляр класса `Game` и запускает игровой процесс, вызывая метод `playGame()`.

### Логика работы

1.  **Инициализация:** `main()` создает объект `Game`, который в свою очередь создает объект `Board` и устанавливает начальное положение шашек.
2.  **Игровой цикл:** `Game::playGame()` запускает цикл, который продолжается до тех пор, пока игрок не введет "exit".
    *   Выводится текущее состояние доски.
    *   Запрашивается ход у текущего игрока.
    *   Ввод преобразуется из шахматной нотации в координаты.
    *   Проверяется допустимость хода.
    *   Если ход допустим, он выполняется, и происходит переключение игрока.
    *   Если ход недопустим, выводится сообщение об ошибке.
3.  **Завершение:** При вводе "exit" игра завершается.

**Примечание 1:** В текущей версии не реализована логика определения победителя или ничьей. Также отсутствует возможность отмены хода.

**Примечание 2:** Изначально реализовывалась шахматная партия, из-за чего некоторые могут присутствовать "излишества". В конечной версии нет подклассов для каждой из фигуры, ибо они различаются только цветом и направлением, а не самой системой ходов.
